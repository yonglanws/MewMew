# Agent 表情包发送逻辑设计

## 目标

让 Agent 按“情绪文件夹名称”选择表情包，并在对应文件夹内随机发送图片；提供可持久化的发送频率设置，同时保持开启流式输出时不发送表情包的既定行为。

## 核心规则

1. `<sticker name="开心"/>` 中的 `name` 对应 `StickerFolder.name`，不是 `StickerItem.name`。
2. 解析时只使用当前会话人格已绑定表情包组中的文件夹。
3. 找到匹配情绪文件夹后，从该文件夹内的有效图片中随机选择一个 `StickerItem`，消息保存选择后的 `stickerId`。
4. `streamOutputEnabled == true` 时不向系统提示词注入表情包规则，也不解析表情包标签。
5. 发送频率为 0～100% 的概率设置：0% 禁用，100% 不拦截；默认 10%。单条消息最多仍为 2 个表情包。
6. 图片缺失或历史消息引用的表情包已删除时，显示明确的不可用占位内容。

## 兼容与边界

- 保留表情包名称字段用于旧数据兼容，但 Agent 可用清单改为情绪文件夹名称与描述。
- 同名情绪文件夹在当前人格可用范围内合并为候选图片池。
- 无匹配文件夹、文件夹为空、文件路径为空或图片不存在时，不生成 sticker 消息，不读取未绑定人格的图片。
- 流式输出关闭后仍使用 API 的流式传输完成响应，但只在响应结束时解析表情包，以保留现有交互设定。

## 设置界面

在设置页的“角色与对话”分组增加“表情包发送频率”入口，进入独立设置页使用 Slider 调整 0～100%，副标题显示当前值和流式输出限制说明。

## 验证范围

- 设置默认值、范围裁剪和 SharedPreferences 持久化。
- 情绪文件夹匹配与文件夹内随机选择。
- 人格绑定过滤、空文件夹和无效文件路径。
- 流式输出开关的禁用行为。
- 频率 0%/100% 边界、单条最多 2 个。
- 历史消息缺失表情包时的占位显示。
