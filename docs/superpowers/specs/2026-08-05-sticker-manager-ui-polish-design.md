# 表情包管理器界面优化设计

## 目标

在不改变表情包发送和配置数据逻辑的前提下，提升表情包管理器的人格列表与人格详情页的信息层级和可扫读性。

## 设计

- 人格列表使用卡片式信息展示，突出头像、人格名称、绑定组数量、发送频率和偏好情绪数量。
- 人格详情页将发送频率放在最上方，方便快速调整。
- 表情包组使用组内首张有效表情包作为缩略图，没有图片时显示表情包组图标。
- 情绪分组使用分组内首张有效表情包作为缩略图，没有图片时显示文件夹图标。
- 绑定组和偏好情绪仍使用可点击的筛选标签，保存行为和现有逻辑保持一致。
- 保留无分割线、圆角卡片、右下角保存按钮和现有主题色。

## 验证

- 页面测试验证人格列表的新信息项、频率区块位置和组/情绪缩略图入口。
- 运行完整 `flutter test`、`flutter analyze --no-fatal-infos` 和 `git diff --check`。
